Livrable 1 · Classification

Photo, peinture ou autre ?

Coche un ou plusieurs classifieurs pour les charger, puis dépose une image : chacun dit si c'est une photo, une peinture ou autre chose, et les verdicts s'affichent côte à côte. Tout reste sur ton ordinateur : aucune image ne part sur Internet.

Dépose tes images ici

glisser-déposer · clic pour parcourir · Ctrl+V pour coller

Le butin

Aucune image pour l'instant. Coche un classifieur à droite, puis dépose des images.

Les classifieurs

Coche un modèle pour le charger, décoche-le pour libérer la mémoire. Chaque image passe dans tous les modèles chargés.

Comment le réseau voit l'image

  1. Redimensionnement à la taille d'entrée du modèle, 200×200 pixels pour les nôtres (bilinéaire, exactement comme TensorFlow à l'entraînement).
  2. Normalisation : chaque pixel est divisé par 255 pour être entre 0 et 1.
  3. Convolutions 3×3 + LeakyReLU + MaxPooling : le réseau repère contours, textures et coups de pinceau, de plus en plus abstraits.
  4. Couche dense qui combine ces indices, puis softmax : une probabilité par classe, la plus haute l'emporte.

Avec le serveur local, c'est le fichier .keras du notebook qui calcule, avec TensorFlow : mêmes résultats que le notebook. En mode navigateur, les poids exportés sont vérifiés à la conversion puis au chargement. Détails des choix (architecture, perte, Adam…) dans le README.md du projet.

Astuces

Indique sous chaque image ce qu'elle est vraiment (« En vrai ») : chaque modèle gagne ou perd un point et sa précision s'affiche. Un modèle qui ne connaît pas la classe « Peinture » est jugé juste s'il répond « Autre ». « Vue du modèle » montre l'image telle que le réseau la reçoit.

Ajouter un classifieur

  1. Enregistre le modèle dans models/ (le notebook le fait en fin d'entraînement).
  2. Ajoute-le dans Test_website/catalogue.json, rubrique L1_classification, avec ses classes dans l'ordre alphabétique des dossiers du dataset.
  3. Recharge cette page (F5) : le serveur relit le catalogue. Pour le mode navigateur, double-clique aussi sur convertir_modeles.bat.

Livrable 2 · Débruitage

Avant / après le débruiteur

Coche un débruiteur pour le charger, puis dépose des photos : chacune passe dans les auto-encodeurs chargés. Fais glisser le curseur sur l'image pour comparer avant et après, et lis le gain : de combien de décibels le PSNR monte une fois le bruit retiré.

Image déposée

glisser-déposer (images ou dossier) · clic pour parcourir · Ctrl+V pour coller

Le miel filtré

Aucune photo pour l'instant. Coche un débruiteur, puis essaie une photo nette : le site lui ajoute du bruit, puis le retire.

Les débruiteurs

Coche un modèle pour le charger. Chaque photo passe dans tous les modèles chargés ; clique sur un nom sous l'image pour l'afficher.

Comment l'image est traitée

  1. Réduction si besoin : le grand côté est ramené à la taille de traitement (le réseau, entièrement convolutif, accepte toutes les tailles).
  2. Normalisation : pixels divisés par 255, entre 0 et 1.
  3. Bords complétés par symétrie jusqu'à un multiple de 8 (trois MaxPooling 2×2), puis rognés à la sortie.
  4. Auto-encodeur (U-Net résiduel) : l'encodeur réduit l'image jusqu'à 1/8 de sa taille, le décodeur la reconstruit avec les détails transmis par les connexions de saut, et le réseau ajoute à l'image la correction qu'il a apprise.
  5. Par tuiles sur les grandes images : des carrés qui se chevauchent d'une marge plus large que le champ de vision du réseau, dont on garde le centre. Le résultat est identique au calcul d'un bloc, et aucun tenseur ne devient assez gros pour fausser la carte graphique.

Lire le gain

PSNR = 10 log10(1 / MSE) entre une image et l'originale propre, en dB : plus haut = plus proche. Le gain est le PSNR de l'image débruitée moins celui de l'image bruitée : +3 dB divise l'erreur par deux. Le SSIM (entre 0 et 1) juge la conservation des contours et des textures.

Ces mesures ont besoin de l'image propre : c'est pourquoi le mode par défaut ajoute lui-même le bruit, comme le notebook. Sur une image déjà bruitée, le site affiche seulement le bruit estimé (méthode d'Immerkær) : il baisse aussi quand des détails fins sont lissés, c'est donc un indice, pas une mesure.

Ajouter un débruiteur

  1. Enregistre le modèle dans models/ (le notebook L2 le fait en fin d'entraînement).
  2. Ajoute-le dans Test_website/catalogue.json, rubrique L2_debruitage.
  3. Recharge cette page (F5). Pour le mode navigateur, double-clique aussi sur convertir_modeles.bat.

Livrable 3 · Captioning

Une phrase pour chaque image

Coche BLIP pour le charger, puis dépose des images : le modèle vision-langage retenu par le notebook L3 écrit une légende pour chacune. Change les réglages de génération pour voir leur effet : chaque nouvelle légende d'une image est gardée sous la précédente.

Dépose tes images ici

glisser-déposer (images ou dossier) · clic pour parcourir · Ctrl+V pour coller

Les légendes

Aucune image pour l'instant. Coche BLIP à droite, puis dépose une photo.

Le légendeur

BLIP, enregistré par Livrable3/L3_2_BLIP.ipynb dans models/. Coche-le pour le charger (quelques secondes), décoche-le pour libérer la mémoire.

Comment BLIP écrit la légende

  1. Image redimensionnée en 384×384 et découpée en 576 carrés de 16×16 pixels.
  2. Encodeur ViT (12 couches d'auto-attention) : chaque carré devient un vecteur de 768 valeurs qui tient compte de toute l'image.
  3. Décodeur de texte (12 couches, de type BERT) : il part de l'amorce et ajoute un sous-mot à la fois ; à chaque couche, une attention croisée regarde les 576 carrés.
  4. Recherche en faisceau : on garde les phrases commencées les plus probables, et à la fin la meilleure.

Le modèle à attention des workshops (CNN + GRU), entraîné de zéro sur 2 900 images, a été abandonné : Livrable3/L3_1_modele_workshops.ipynb montre pourquoi, L3_2_BLIP.ipynb compare les deux.

Lire les réglages

Amorce : BLIP a été affiné sur COCO avec une amorce (« a picture of ») ; en donner une l'oriente vers une description factuelle, sans amorce la légende est libre. Faisceau : plus d'hypothèses, phrases plus sûres mais plus lentes ; 1 = glouton. Répétitions interdites : 2 empêche « a dog and a dog ». Pénalités : au-dessus de 1, la répétition est découragée et les phrases longues favorisées. L'échantillonnage rend la phrase aléatoire : utile pour voir les autres descriptions que le modèle juge possibles.

BLIP écrit en anglais : il a appris sur des légendes anglaises.
