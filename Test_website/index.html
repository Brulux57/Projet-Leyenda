Les modèles de la ruche

Chaque image passe dans tous les modèles activés.

Comment le réseau voit l'image

  1. Redimensionnement à la taille d'entrée du modèle, 200×200 pixels pour les nôtres (bilinéaire, exactement comme TensorFlow à l'entraînement).
  2. Normalisation : chaque pixel est divisé par 255 pour être entre 0 et 1.
  3. Convolutions 3×3 + LeakyReLU + MaxPooling : le réseau repère contours, textures et coups de pinceau, de plus en plus abstraits.
  4. Couche dense qui combine ces indices, puis softmax : une probabilité par classe, la plus haute l'emporte.

Les poids sont exportés depuis Keras et vérifiés à la conversion : le site donne les mêmes résultats que le notebook. Détails des choix (architecture, perte, Adam…) dans le README.md du projet.

Ajouter un modèle

  1. Crée un dossier dans modeles/ (par exemple modeles/V3).
  2. Mets-y ton fichier .keras et, si tu veux, un classes.txt avec un nom de classe par ligne (dans l'ordre alphabétique des dossiers du dataset).
  3. Double-clique sur convertir_modeles.bat.
  4. Recharge cette page (F5).

Astuces

Indique sous chaque image ce qu'elle est vraiment (« En vrai ») : chaque modèle gagne ou perd un point et sa précision s'affiche. Un modèle qui ne connaît pas la classe « Peinture » est jugé juste s'il répond « Autre ». « Vue du modèle » montre l'image telle que le réseau la reçoit.
