# TensorFlow et PyTorch partagent les bibliothèques CUDA de l'environnement : ils doivent utiliser la même
# version majeure de CUDA. TensorFlow 2.21 est compilé pour CUDA 12 ; PyTorch est donc pris dans sa version CUDA 12.9
# (index ci-dessous), qui gère aussi les cartes RTX 50xx. Une version de PyTorch compilée pour CUDA 13 (cu130) installe
# ses bibliothèques CUDA 13 dans les mêmes dossiers nvidia/ (cudnn, nccl...) que celles de TensorFlow.
# TensorFlow 2.21 ne trouve pas seul libcusolver.so.11 dans l'environnement et abandonne alors la carte graphique
# (« Cannot dlopen some GPU libraries ») : installer_environnement.sh copie leyenda_cuda.py dans l'environnement, qui la
# charge juste avant le premier import de TensorFlow.
